# ``Waypoint``

Coordinate navigation stacks, tabs, and presentations while your SwiftUI app owns its views.

@Options {
    @TopicsVisualStyle(detailedGrid)
}

## Overview

Waypoint stores navigation and presentation intent in observable, main-actor
routers. Bind their state to SwiftUI to display destinations and sheets, and use
the window bridge to forward scene requests. Start with <doc:GettingStarted>.
The app supplies destination views, scene registrations, and persistence.
